### Column 1: Agentic Search
```
No Vector Databases Required

Like Claude Code, Knowledge Hub uses agentic search:
- File system traversal
- Content search (grep-like)
- Tool-based exploration
- No embeddings, no vector complexity

Simple. Transparent. Inspectable.
```

### Column 2: Playbook System
```
Corrections That Persist

When agents make mistakes, corrections become Playbooks:
- YAML format (human-readable)
- Git-friendly (version control)
- Pattern matching (apply to similar cases)
- Confidence scoring (when to use vs. search)

Deterministic. Auditable. Improvable.
```

### Column 3: Hybrid Approach
```
Best of Both Worlds

Playbooks + Agentic Search = Reliable agents:
- Check Playbooks first (trained knowledge)
- Fall back to search (flexibility)
- Learn from corrections (systematic improvement)
- Track accuracy over time (prove ROI)

Production-ready. Enterprise-grade.

## FAQ SECTION

### Heading
```
Frequently Asked Questions
```

### Q1: How is this different from RAG frameworks?
```
RAG frameworks (LangChain, LlamaIndex) provide retrieval, but no training layer.

Knowledge Hub adds Playbooks - persistent corrections that improve accuracy over time.

Think of RAG as "search" and Playbooks as "training data" - you need both.
```

### Q2: Do I need vector databases?
```
No. Knowledge Hub uses agentic search (like Claude Code) - file operations, not vectors.

Simpler architecture. No embedding costs. No vector DB complexity.

Just files, LLM, and Playbooks.
```

### Q3: What LLMs does it work with?
```
Any LLM with function/tool calling:
- Claude (recommended for best agentic performance)
- GPT-4 / GPT-4o
- Local models via Ollama
- Custom models

Pluggable architecture - bring your own LLM.
```

### Q4: Is this only for document Q&A?
```
No. Knowledge Hub works for ANY agentic workflow.

Starting with document Q&A (RAG) because it's the simplest use case.

Expanding to task automation, code generation, data analysis, etc.
```

### Q5: Will there be a hosted version?
```
Yes, eventually - if the community validates demand.

Open source will always be free and self-hosted.

Hosted version would be for teams who want managed infrastructure, collaboration features, and support.
```

### Q6: When can I use it?
```
Target launch: November 2025
